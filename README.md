# Calculadora Lab 7

## Instalación
```bash
yarn install
```

## Correr la app
```bash
yarn dev
```

## Correr tests
```bash
yarn test
```

## Linting
```bash
yarn lint
```

## Storybook
```bash
yarn storybook
```
